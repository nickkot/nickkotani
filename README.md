# nickkotani

Personal site for Nick Kotani. It's plain HTML and CSS, with no build step.

- `index.html`: all of the page content
- The four styles (Minimal, SF Bay, Scoreboard, Retro) live in the `<style>` block in `index.html` and are set by `data-theme` on `<html>`
- `PERSONAL_SITE_PROMPT.md`: the interview prompt this site came from

Open `index.html` in a browser to preview it. Switch looks with the **Style** bar at the top, the **Next ↻** button, or the `S` key. Your last pick is remembered. Once you pick one, set it as the default in the script at the bottom of `index.html`, or remove the switcher.

## Deploy (GitHub Pages)
Repo **Settings → Pages → Deploy from a branch**, then pick the branch and `/ (root)`.
