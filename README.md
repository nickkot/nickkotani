# nickkotani

Personal site for Nick Kotani. It's plain HTML and CSS, with no build step.

- `index.html`: all of the page content
- `styles.css`: the four styles (Minimal, SF Bay, Scoreboard, Retro), set by `data-theme` on `<html>`
- `PERSONAL_SITE_PROMPT.md`: the interview prompt this site came from

Open `index.html` in a browser to preview it. Use the **Style** bar at the top to switch looks. Once you pick one, set it as the default in the script at the bottom of `index.html`, or remove the switcher.

## Deploy (GitHub Pages)
Repo **Settings → Pages → Deploy from a branch**, then pick the branch and `/ (root)`.
